# Proyecto final Power BI

**Alumna:** Aya Hibat Allah Aichoune  
**Módulo:** Power BI · Análisis y Visualización de Datos

Informe de ventas, logística y satisfacción del cliente del marketplace brasileño Olist (enero de 2017 a agosto de 2018).

## Cómo abrir el trabajo

1. Descarga este repositorio (botón **Code** → **Download ZIP**, o clona el repositorio).
2. Abre `Aichoune_AyaHibatAllah_TrabajoPBI.pbix` con **Power BI Desktop**.
3. La memoria del proyecto está en `Aichoune_AyaHibatAllah_TrabajoPBI.docx`.

## Contenido

- `Aichoune_AyaHibatAllah_TrabajoPBI.pbix` — informe de Power BI (modelo, medidas DAX y visualizaciones).
- `Aichoune_AyaHibatAllah_TrabajoPBI.docx` — documento explicativo.
- `Aichoune_AyaHibatAllah_TrabajoPBI.pbip` — archivo de proyecto de Power BI.
- `Datos_originales/maestros_brasil.xlsx` — maestro propio: estados de Brasil, categorías, estados de pedido y tipos de pago.
- `Datos_originales/olist_brazilian_ecommerce_kaggle.zip` — dataset original de Olist (Kaggle).

## Datos

- [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), licencia CC BY-NC-SA 4.0.
- `maestros_brasil.xlsx`, elaboración propia.
